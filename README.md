# vnpilot 

## File Structure
```
game
├───assets               - non-ui static game assets 
│   ├───audio            - all sound assets
│   │   ├───music        - background music tracks
│   │   └───sfx          - sound effects
│   ├───fonts            - custom fonts used in the game
│   ├───images           - visual assets used in scenes
│   │   ├───bg           - backgrounds 
│   │   ├───cg           - CGs 
│   │   └───sprites      - character sprites 
│   └───video            - cutscenes or animated sequences
│
├───characters           - character definitions and related logic
│                         
│
├───gui                  - UI asset files used by screens and styles
│
├───screens              - UI layout and presentation logic
│                         
│
├───story                - narrative scripts and dialogue
│                         
│
├───systems              - core gameplay systems and mechanics
│                         
│
└───utils                - reusable helper functions and utilities
                          
```
